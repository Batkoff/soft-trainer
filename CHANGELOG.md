# История версий

Номер текущей версии отображается внизу тренажёра и админки. Подробности — на `/updates/`.

Источник истории интерфейса — `trainer/releases.py`; при выпуске добавляем запись первой и обновляем этот файл.

## 0.5.0 · 22.09.2026 · Тон. Найди свой.

- Название «Тон», новые тексты входа и главной, favicon и тёмная тема «виноград + лайм».
- Общие цветовые переменные для тренажёра и админки, контрастные состояния форм и статусов.
- @batkoff в общих подвалах страниц, документации и метаданных Docker-образа.
- Единый генератор настроек сохраняет существующие пароли и ключи; восстанавливает файл подсказки входа.
- `scripts/start.py` проверяет Docker и ждёт готовности сервисов; поддерживает `--host` и `--port`.
- Возвращены отсутствовавшие в первом GitHub-коммите `.gitignore`, `.dockerignore` и безопасный шаблон `.env`.
- Docker получает только исходники приложения; локальные секреты не копируются в образ.
- Настроены переносы строк для Windows/Linux. Проект и том PostgreSQL сохраняют имя `soft-trainer`.
- Поддержан прямой HTTPS через Caddy на VPS, добавлены тома сертификатов.
- README описывает продукт; установка, API и VPS вынесены в отдельные инструкции.
- Добавлена проверка чистой Docker-сборки и тестов в GitHub Actions.

## 0.4.0 · 16.09.2026 · Короткие конкурсы, архив и понятные логи

- Репозиторий подготовлен к GitHub/VPS: `.env` и локальные артефакты исключены,
  добавлены `bootstrap_env.py`, VPS-деплой и переменные `HTTP_BIND/HTTP_PORT`.

- В карточке конкурса появилась кнопка «Завершить досрочно» с подтверждением.
  Приём прекращается сразу; сохранённые черновики отправляются на проверку.
  Очередь и спорные работы не теряются. Когда все оценки готовы, рейтинг
  фиксируется автоматически (проверка раз в минуту) либо кнопкой администратора.
- Плановая дата окончания сохраняется; фактическое раннее закрытие записывается
  отдельно. Запуск задания, пересмотр и закрытие согласованы блокировкой конкурса.
- Выпадающий список заменён карточками конкурсов. Выбор сохраняется между
  страницами. Главная предпочитает доступный конкурс будущему и завершённому.
- Завершённые конкурсы доступны в архиве с явной датой фиксации и неизменной
  таблицей. Приём ответов и пересмотр итоговых оценок закрыты.
- Поля сроков: 00:00:00 по умолчанию, ввод до секунд, без миллисекунд, время МСК.
  Вместо общей ошибки показаны будущий старт или ожидание итогов.
- Журнал действий получил русские названия, статусы с цветом и ссылки на trace.
  Промпт и JSON-ответ читаются с переносами. Исторический повтор не выдаётся за
  актуальное состояние: в карточке отдельно показано, что происходит сейчас.
- TXT-выгрузка отдельной записи, выбранных записей и всего отфильтрованного списка;
  JSON-выгрузка сохранена. Во всех endpoints проверяются права просмотра модели.
- Исправлена ошибка из присланных логов: завершающая точка, добавленная моделью,
  больше не отменяет разбор. В цитате показывается фактический текст сотрудника;
  изменения слов и чисел по-прежнему отклоняются. При ошибке указаны поле и факт.
- Миграция `0005` добавляет фактическое закрытие и уточняет название статуса повторов.

## Как выпускаем изменения

Каждый выпуск получает номер MAJOR.MINOR.PATCH: новые возможности увеличивают MINOR, исправления — PATCH.
Код, миграции, история и проверенный статус входят в архив. Секреты и рабочая база хранятся отдельно.
Перед обновлением делаем резервную копию. Незавершённые задачи переносим в BACKLOG.md.
