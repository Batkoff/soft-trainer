# Тон. Найди свой.

Браузерный тренажёр общения для сотрудников поддержки. Сотрудник получает сообщение клиента и готовый, правильный по содержанию ответ. За три минуты нужно переписать его понятным человеческим языком, сохранив факты, сроки и ограничения.

Нейросеть отдельно проверяет содержание и качество общения. Существенное искажение hard-информации обнуляет рейтинговый балл, но сотрудник всё равно получает разбор soft skills. Спорную оценку может пересмотреть администратор.

Проект создан для проверки идеи обучения поддержки малого бизнеса. Учебные задания вымышлены; подключения к системам банка нет.

## Возможности

- Ежедневные задания с лимитом и серверным таймером.
- Сохранение черновика, очередь проверки и повторы при временных сбоях API.
- Оценка через OpenRouter или OpenAI; настройка ключа и модели на сайте.
- Конкурсы, рейтинг, призы, досрочное завершение и архив итогов.
- Песочница администратора без рейтинговых баллов.
- Управление заданиями, пользователями и доступом; аналитика и пересмотр оценок.
- Диагностика запросов к модели и выгрузка журналов.

## Запуск

Нужны Python 3.10+ и Docker с Compose. На Windows установите Docker Desktop и включите Linux containers.

```bash
git clone https://github.com/Batkoff/soft-trainer.git
cd soft-trainer
python scripts/start.py
```

На Windows также можно открыть `start.bat` двойным кликом. На Linux/macOS используйте `python3`, если команды `python` нет.

Скрипт создаст локальные секреты, поднимет базу, применит миграции и запустит сайт по адресу **http://localhost:8080**. Проверенные данные входа в `admin` будут в `.demo-credentials.txt`. Обычное обновление не сбрасывает существующие пароли. Для восстановления забытого пароля:

```bash
python scripts/start.py --reset-admin
```

После входа откройте **Управление → Нейросеть**, выберите модель и вставьте API-ключ. Проверьте ответ в песочнице, затем запустите стартовый конкурс из черновика. Без ключа сайт работает, но оценки не подставляются.

Django, PostgreSQL, Procrastinate, Gunicorn, Caddy. Интерфейс — серверные HTML-шаблоны, CSS и HTMX. Для запуска не нужны Redis, Node.js или отдельная сборка интерфейса.
