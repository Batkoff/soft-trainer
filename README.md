# Тон

**Найди свой.**

Браузерный тренажёр общения для сотрудников поддержки. В каждом задании уже есть правильный по содержанию ответ: решение, сроки и ограничения. Сотруднику остаётся превратить его в понятное, спокойное и человечное сообщение — сохранив факты.

Проект вырос из идеи тренировки soft skills для поддержки малого бизнеса Т-Банка. Это самостоятельный прототип: он не подключается к банковским системам и не требует реальных клиентских данных.

Автор и сопровождающий — **[Даниил Батков · @batkoff](https://github.com/Batkoff)**.

## Как проходит тренировка

1. Сотрудник видит сообщение клиента и готовый ответ с обязательными фактами.
2. За три минуты формулирует свою версию. Черновик сохраняется, таймер продолжает идти после закрытия вкладки.
3. Ответ отправляется на проверку. При очереди можно закрыть страницу: результат сохранится в истории.
4. Сотрудник получает разбор содержания и soft skills: что получилось, что улучшить и возможный вариант ответа.

Например, исходный текст:

> Возврат находится в обработке. Срок зачисления — до 3 рабочих дней. Ускорить операцию невозможно.

Вариант сотрудника:

> Понимаю, что ожидание затянулось. Возврат уже обрабатывается, деньги поступят в течение 3 рабочих дней. Ускорить зачисление, к сожалению, не получится.

Задача — подобрать слова. Новые обещания, сокращённые сроки и выдуманные условия не считаются улучшением ответа.

## Что есть в приложении

| Раздел | Возможности |
|---|---|
| Тренировка | Дневной лимит заданий, серверный таймер, сохранение черновика, очередь проверки |
| Оценка | Проверка hard-информации, пять soft skills, объяснения и ручной пересмотр |
| Конкурсы | Участники, сроки, призы, рейтинг, досрочное завершение и архив итогов |
| Песочница | Проверка заданий и моделей без рейтинговых баллов |
| Управление | Добавление заданий, версии опубликованных заданий, пользователи и роли |
| Аналитика | Результаты работ, спорные оценки, калибратор на эталонных ответах |
| Диагностика | Журнал действий, запросы и ответы оценщика, ошибки, выгрузка TXT и JSON |
| Профиль | Отображаемое имя и выбор аватара |

При существенном искажении обязательных фактов **рейтинговый балл равен нулю**, но разбор soft skills остаётся. При сбое модели работа сохраняется; временные ошибки повторяются через очередь. Неоднозначные оценки можно пересмотреть с указанием причины.

Дневной лимит делает конкурс соревнованием по качеству ответов. После завершения и проверки всех работ итоговый рейтинг фиксируется. Призы показываются в интерфейсе; автоматической выплаты T-Money нет.

## Запуск

Нужны Docker с Compose v2 и Python 3.10+ для стартового скрипта.

```bash
git clone https://github.com/Batkoff/soft-trainer.git
cd soft-trainer
python scripts/start.py
```

Откройте **http://localhost:8080**. Начальный пароль лежит в созданном локально `.demo-credentials.txt`. На Windows также можно запустить `start-demo.bat`; на Linux/macOS вместо `python` обычно используется `python3`.

**Первый запуск без опыта → [пошаговая инструкция](docs/GETTING_STARTED.md).**

По умолчанию используется демонстрационный оценщик без внешних запросов. Его баллы предназначены для проверки механики. Реальный разбор подключается через API OpenAI или OpenRouter; ключи хранятся в локальном `.env`.

## Стек

- **Django** — сервер, страницы, авторизация и управление.
- **PostgreSQL** — задания, ответы, результаты и очередь.
- **Procrastinate** — фоновая оценка, повторы и обслуживание конкурсов.
- **Django Templates, HTMX, CSS и JavaScript** — интерфейс без отдельной frontend-сборки.
- **Gunicorn и Caddy** — запуск приложения, статика и HTTPS на сервере.
- **Docker Compose** — одинаковый состав сервисов на компьютере и VPS.

Отдельные Redis, брокер сообщений и Node.js для запуска не нужны. Начальный пилот рассчитан на небольшую команду. Готовность к пику в 150 одновременных пользователей ещё требуется подтвердить нагрузочными тестами.

## Разработка

```bash
docker compose exec web python manage.py test trainer
python -m unittest discover -s scripts -p "test_*.py"
```

Основные части кода:

```text
config/          настройки Django и маршруты
trainer/         данные, правила тренировки, оценщик, очередь и тесты
templates/       страницы тренажёра и админки
static/          тема, стили, JavaScript и HTMX
scripts/         запуск, настройка и резервное копирование
docs/            инструкции и архитектура
```

Цвета обеих частей интерфейса задаются в `static/theme.css`. Номер версии и история для интерфейса — в `trainer/releases.py`. Условия конкурса и снимки заданий сохраняются отдельно от последующих правок исходных материалов.

Секреты, локальные данные, дампы базы и собранная статика исключены из Git. Docker-образ собирается только из необходимых исходников. Лицензии сторонних компонентов сохраняются вместе с ними.
