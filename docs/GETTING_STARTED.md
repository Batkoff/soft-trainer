# Установка Тона с нуля

Личная некоммерческая установка бесплатна. Установка для компании, включая пилот и обучение сотрудников, требует отдельного платного соглашения. См. [лицензию](../LICENSE).

## 1. Установите программы

- **Git** — чтобы скачать проект и получать обновления.
- **Python 3.10 или новее** — при установке Windows отметьте **Add Python to PATH**.
- **Docker Desktop** — запустите и дождитесь готовности Docker Engine. Используйте режим **Linux containers**. Если установка попросит включить WSL 2 или перезагрузиться, выполните это.

Откройте новый терминал и проверьте:

```bash
python --version
git --version
docker compose version
```

На Linux вместо Docker Desktop можно использовать Docker Engine с Compose. Если команда Python называется `python3`, используйте её в дальнейших шагах.

## 2. Скачайте проект

В Git Bash или PowerShell:

```bash
git clone https://github.com/Batkoff/soft-trainer.git
cd soft-trainer
```

Если вы уже скачали проект, перейдите в его папку, а не клонируйте второй раз. В папке должны быть `compose.yaml`, `README.md` и `start.bat`.

Без Git можно скачать **Code → Download ZIP** на GitHub и распаковать архив. Обновлять такую копию удобнее заменой исходников из нового архива, сохраняя собственный `.env` и данные Docker.

## 3. Запустите

```bash
python scripts/start.py
```

На Windows можно вместо команды дважды нажать `start.bat`. Это тот же запуск.

Первый запуск скачивает образы и зависимости, поэтому занимает дольше последующих. Скрипт сам создаёт `.env` с уникальными секретами, запускает PostgreSQL, проверяет доступ из приложения, применяет миграции и запускает сайт с очередью. При несовпадении пароля сохранённой базы он согласует пароль без удаления данных, если доступно штатное локальное администрирование базы.

Дождитесь сообщения **Тон готов: http://localhost:8080**. Откройте этот адрес в браузере. Контейнер `init` со статусом `Exited (0)` — нормальное завершение подготовки.

## 4. Войдите

Откройте локальный файл `.demo-credentials.txt`. Он содержит проверенный логин и пароль администратора либо инструкцию восстановления, если начальный пароль уже меняли.

Если пароль забыт:

```bash
python scripts/start.py --reset-admin
```

Новый случайный пароль `admin` появится в том же файле. Остальные учётные записи, задания и результаты сохранятся. Пароль PostgreSQL не предназначен для входа на сайт.

## 5. Подключите оценку

1. Под `admin` откройте **Управление → Нейросеть**.
2. Выберите провайдера и модель, вставьте API-ключ и сохраните.
3. Откройте песочницу, напишите ответ и дождитесь разбора.
4. В **Конкурсах** откройте стартовый черновик. Проверьте сроки, участников и задания, затем запустите конкурс действием в админке.

Перезапуск после сохранения ключа не нужен. Без подключения сервис не выставляет подставные оценки. Старые конкурсы с тестовыми баллами сохраняются в истории; для реальной оценки нужен новый конкурс.

Ключ сохраняется зашифрованным. Храните резервную копию `.env` вместе с базой: `SECRET_KEY` нужен для расшифровки.

## Остановка и повторный запуск

```bash
docker compose stop
python scripts/start.py
```

Не выполняйте `docker compose down -v`: эта команда удаляет тома с данными.

## Открыть другу по локальной сети

Узнайте IPv4 своего компьютера командой `ipconfig`, затем укажите его:

```bash
python scripts/start.py --host 192.168.1.50
```

Замените пример своим адресом. Друг должен находиться в той же сети и открыть `http://ВАШ_IP:8080`. Разрешите входящие подключения к этому порту в локальном брандмауэре. Для доступа через интернет нужен сервер с HTTPS.

## Обновление

Обновления публикуются в ветке `develop`. Если у вас есть собственные изменения, сначала сохраните их коммитом.

```bash
git switch develop
git pull --ff-only origin develop
python scripts/start.py
```

Ключи и пароли сохраняются, миграции применяются автоматически. Если стили в браузере старые — **Ctrl+F5**.

## Если не запустилось

| Сообщение | Что сделать |
| --- | --- |
| Docker не найден | Установить Docker Desktop и открыть новый терминал |
| Docker Engine недоступен | Дождаться запуска Desktop; выполнить `docker info` |
| Порт занят | Запустить `python scripts/start.py --port 8081` |
| `init` завершился с ошибкой | Посмотреть журнал ниже; база остаётся на месте |
| `password authentication failed` у PostgreSQL | Повторить `python scripts/start.py`; при изменённых вручную правилах доступа потребуется исходный пароль базы |
| Пароль сайта не подходит | Выполнить `python scripts/start.py --reset-admin` |
| `400 Bad Request` или ошибка CSRF при сетевом входе | Повторить запуск с `--host` и нужным адресом |
| Оценка не пришла | Открыть запросы к нейросети в админке; проверить ключ, модель и баланс провайдера |

```bash
docker compose ps -a
docker compose logs --no-color --tail=100 init web worker proxy
```

При обращении за помощью отправляйте ошибку и журнал, а не `.env`, файл паролей или API-ключ. Скрипт запуска скрывает известные ему секреты в автоматически выводимой диагностике.
