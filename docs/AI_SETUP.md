# Подключение оценки текста

Первый запуск работает без ключей в демонстрационном режиме. Для реальной оценки нужен API-ключ OpenAI или OpenRouter и доступная в аккаунте модель. Подписка ChatGPT не заменяет API-ключ.

## Через файл настроек

Откройте `.env` в папке проекта. Замените существующие строки, не добавляя дубликаты:

```dotenv
EVALUATOR_BACKEND=openrouter
EVALUATOR_MODEL=nvidia/nemotron-3-super-120b-a12b:free
OPENROUTER_API_KEY=ваш-ключ
```

Это пример модели, с которой проверялась интеграция. Доступность, квоты и условия бесплатных моделей меняются; перед подключением проверьте выбранную модель в своём аккаунте. Автоматического перехода на платную модель нет.

Для прямого OpenAI:

```dotenv
EVALUATOR_BACKEND=openai
EVALUATOR_MODEL=gpt-4.1-mini-2025-04-14
OPENAI_API_KEY=ваш-ключ
```

Подключаемая модель должна поддерживать Chat Completions, JSON Schema и параметры адаптера в `trainer/evaluation_http.py`.

Примените настройки:

```bash
python scripts/start.py
```

Войдите администратором и откройте **Песочница → Реальная оценка нейросетью**. Создайте новую попытку. Уже существующие попытки и конкурсы сохраняют прежний профиль оценки; для рейтинга с новой моделью создайте новый конкурс.

## Через мастер

```bash
python scripts/configure_ai.py
```

Мастер предлагает провайдера и скрытый ввод ключа. При вводе не показываются ни символы, ни звёздочки: вставьте ключ и нажмите Enter. В Windows удобнее PowerShell. Если терминал не поддерживает скрытый ввод, используйте `.env`, как описано выше.

Мастер только сохраняет настройки: баланс и доступность модели проверяются при реальном запросе.

## Как работает разбор

1. Ответ сохраняется в базе и попадает в очередь.
2. Модель проверяет обязательные факты и оценивает пять soft skills.
3. Приложение проверяет формат ответа и рассчитывает итог по весам навыков.
4. При существенном искажении hard-информации рейтинговый балл равен нулю, но soft-разбор остаётся.
5. При неоднозначности результат ждёт ручной проверки.

Временный сбой допускает до трёх попыток запроса суммарно. Каждый запрос может расходовать квоту провайдера. После исчерпания попыток работа остаётся доступна администратору для повтора или пересмотра. Пустой просроченный ответ проверяется локально.

Промпт — `trainer/evaluation_prompt.py`. Параметры фиксируются в профиле конкурса. Менять правила посреди конкурса нельзя.

## Диагностика

В админке есть **Диагностика API**: запрос, промпт, ответ модели, результат проверки формата, токены, время и причина ошибки. Записи можно выгружать в TXT и JSON. Ключ авторизации в этих записях не сохраняется.

Для технических ошибок очереди:

```bash
docker compose logs --tail=100 worker
```

API получает учебный контекст и ответ сотрудника. Используйте вымышленные примеры без реальных клиентских данных. До конкурса с призами откалибруйте модель на эталонах и согласуйте критерии с руководителями.
